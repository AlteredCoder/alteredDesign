# Existing website and screenshot fidelity

**Load when:** recreating, mocking up, redesigning or drawing inspiration from existing UI.
**Owns:** source capture, visual measurements, asset selection and comparison.
**Defaults:** preserve identity for recreation; record deliberate changes for redesign.

## Inspect the source

- **SRC-01 — Name the reference role.** MUST: label each reference recreation, redesign source, or inspiration. A blank local repository does not make an existing-site request aesthetically open. Check: the brief states what must match and what may change.
- **SRC-02 — Look before building.** MUST: open and visually inspect the supplied site or screenshot at its known viewport; inspect relevant lower sections and responsive states when available. If access fails, disclose it and use supplied visual evidence without claiming to have seen the live site. Check: record source URL or path, viewport and observed composition.
- **SRC-03 — Capture defining decisions.** MUST: record main proportions, section order, type family or closest evidenced match, weights, line breaks, colors, image crop, surface treatment and control geometry. Separate measurements from estimates. Check: the plan contains concrete source-derived decisions rather than only adjectives.
- **SRC-04 — Assets determine the composition.** MUST: inspect brand marks, font files and imagery; reuse supplied or authorized assets where available. Report substitutions of defining imagery or fonts. Check: the asset inventory names each source, role and substitution.

## Compare and correct

- **SRC-05 — Match the viewport.** MUST: render at the reference's width and height, with fonts and images settled, before making fidelity claims. Compare equivalent content and state. Check: source and output dimensions and states are recorded together.
- **SRC-06 — Fix large differences first.** MUST: compare page silhouette, region proportions and dominant imagery first; then typography, spacing, color and detail. Re-render after corrections. Do not rewrite source composition to satisfy a default grid or anti-pattern preference. Check: remaining major mismatches are fixed or identified in the handover.
- **SRC-07 — Responsive evidence.** SHOULD: match supplied narrow references; with desktop evidence only, infer a usable narrow layout and label that adaptation as inferred. Check: no claim of mobile source fidelity without mobile evidence.
- **SRC-08 — Distinguish inspiration from assets.** MUST: use the gallery as visual evidence, not as customer logos, testimonials or imagery to silently insert into the product. Check: asset reuse follows supplied permissions and usage terms; reference credits remain attached.

## Quick check

- SRC-01 · recreate, redesign or inspiration explicit
- SRC-02 · source seen or limitation stated
- SRC-04 · defining assets preserved or substitutions disclosed
- SRC-05 · equivalent viewport and state compared
- SRC-06 · large mismatches addressed
